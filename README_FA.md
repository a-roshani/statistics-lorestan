# درگاه گروه آمار دانشگاه لرستان

این پوشه نسخه عمومی و آماده GitHub Pages است.

## نکته امنیتی مهم
در نسخه عمومی هیچ دکمه یا صفحه مدیریتی وجود ندارد. تنظیمات فقط از طریق فایل `data/portal-config.js` انجام می‌شود.
ویرایشگر مدیریتی در یک فایل ZIP جداگانه ارائه شده و نباید در GitHub آپلود شود.

## فایل‌های اصلی
- `index.html`: صفحه اصلی سایت
- `data/portal-config.js`: تمام متن‌ها، کلیدها، لینک‌ها و اطلاعات تماس
- `assets/group-logo-mark.png`: لوگوی گروه برای نمایش در سایت
- `assets/group-logo-full.jpg`: نسخه کامل لوگوی ارسالی
- `files/`: فایل‌هایی که کلیدهای سایت به آن‌ها متصل هستند

## جایگزینی فایل‌های واقعی
فایل‌های نمونه را می‌توانید با فایل‌های واقعی خود جایگزین کنید. ساده‌ترین روش این است که نام فایل جدید را همان نام فعلی نگه دارید:
- `files/chart-402.html`
- `files/chart-404.html`
- `files/syllabus-402.html`
- `files/syllabus-404.html`
- `files/weekly-4051.html`

یا مسیر فایل را در `data/portal-config.js` یا با ویرایشگر محلی تغییر دهید.

## ویرایش بدون دستکاری کد
1. فایل `local-editor.html` را از بسته ویرایشگر محلی روی کامپیوتر خود باز کنید.
2. با گزینه «وارد کردن portal-config.js»، فایل فعلی `data/portal-config.js` را انتخاب کنید.
3. عنوان‌ها، توضیحات، آیکن‌ها، لینک فایل‌ها، رفتار کلیک، ترتیب کلیدها، نمایش/عدم نمایش و اطلاعات تماس را ویرایش کنید.
4. فایل جدید `portal-config.js` را خروجی بگیرید.
5. آن را در پوشه `data/` پروژه عمومی جایگزین و در GitHub Commit کنید.

## انتشار با GitHub Pages
1. یک Repository بسازید.
2. تمام محتویات این پوشه را در ریشه Repository قرار دهید؛ `index.html` باید در ریشه باشد.
3. به `Settings > Pages` بروید.
4. `Deploy from a branch` را انتخاب کنید.
5. Branch را `main` و Folder را `/(root)` قرار دهید.
6. ذخیره کنید و منتظر لینک GitHub Pages بمانید.
